# FTIR 备课知识与老师提问答疑

面向首次接触 FTIR 的大学生课程。核对日期：2026 年 10 月 9 日。**本文件用于课前理解与课后答疑，不需要在讲稿中逐项讲出。**先掌握“必记 10 条”和必答题，再选择进阶内容。网页中的高级实验用于验证关系，不能替代真实仪器操作规程。

## 一、上台前必记 10 条

1. FTIR 是傅里叶变换红外光谱技术；这里讲的是常见的透射吸收测量。
2. 红外吸收需要能量匹配，还需要相应振动具有红外活性；具有永久偶极矩不是必要条件。
3. 波数 ν̃ = 1/λ。波数越大，频率与光子能量越大；这里的波数不是“有多少束光”。
4. 分束器把同一束光送入两臂。动镜改变路程，不逐个挑选波长。
5. 正入射、空气近似下，镜子移动 Δx，光程差改变 2Δx，因为光要往返。
6. 干涉图横轴是光程差，纵轴是探测响应。它不是分子的振动轨迹，也不是吸光度谱。
7. 不同波数在光程差轴上留下不同周期；这些强度调制贡献相加成一条记录。
8. 傅里叶变换把整条记录中的周期信息恢复成单光束谱；还需参比才能得到透射率和吸光度。
9. T = B样品/B背景；A = −log₁₀ T。T = 0.1 时，%T = 10%，A = 1。
10. 光谱提供结构线索。鉴定要结合完整谱形、相态、测量方式和其他证据；一个峰不能独自证明身份。

## 三、原理备查：从分子到结果

### 1. 波数、频率、能量是什么关系？

| 量 | 符号与单位 | 意义 |
|---|---|---|
| 波长 | λ，μm 或 cm | 一个空间周期的长度 |
| 频率 | ν，Hz | 每秒振荡次数 |
| 波数 | ν̃，cm⁻¹ | 波长用 cm 表示时的倒数 |
| 光程差 | δ，cm 或 μm | 两臂往返光程之差 |
| 镜位移 | x，cm 或 μm | 动镜的机械位置变化 |

采用真空波长：ν̃ = 1/λ；ν = c₀ν̃；E = hₚν = hₚc₀ν̃。若 ν̃ 用 cm⁻¹，光速用 c₀ = 2.9979×10¹⁰ cm/s。hₚ 表示普朗克常数，避免与网页采样间距 h 混淆。

便于心算：λ/μm = 10000/(ν̃/cm⁻¹)；E/eV ≈ 1.23984×10⁻⁴ × (ν̃/cm⁻¹)。

| 波数 | 波长 | 光学频率 | 单个光子能量 |
|---:|---:|---:|---:|
| 1000 cm⁻¹ | 10 μm | 约 30 THz | 约 0.124 eV |
| 1700 cm⁻¹ | 约 5.88 μm | 约 51 THz | 约 0.211 eV |
| 3000 cm⁻¹ | 约 3.33 μm | 约 90 THz | 约 0.372 eV |

网页展示的 4000–400 cm⁻¹ 对应 2.5–25 μm，是常见中红外分析范围。光谱从左到右波数递减是常用绘图习惯；物理规律不会因坐标方向而改变。[Thermo Fisher：FTIR 教学资料](https://www.thermofisher.com/us/en/home/industrial/spectroscopy-elemental-isotope-analysis/molecular-spectroscopy/fourier-transform-infrared-spectroscopy/resources/ftir-spectroscopy-academy.html)

### 2. 为什么不同化学键有不同的吸收位置？

低振幅下可把伸缩近似为谐振子。双原子或局部键近似给出：

**ν̃₀ = [1/(2πc₀)]√(K/μ)，μ = m₁m₂/(m₁+m₂)。**

K 是力常数，μ 是约化质量；使用 SI 的 K（N/m）、μ（kg）、c₀（m/s）时，得到 m⁻¹，除以 100 才是 cm⁻¹。在相似环境下，力常数越大频率越高，约化质量越大频率越低。这是理解趋势的模型；多原子分子的正常模式可能同时牵动多个原子，不能把每个峰机械地对应为一根键。

量子谐振子能量：Eᵥ = (v+½)hₚν₀。最低能级仍有零点能。能级图画的是能量，不是原子位置；动画展示的是模式的运动关系，不是实时拍到分子。真实分子存在非谐性、环境耦合和有限线宽。[OpenStax：分子能谱](https://openstax.org/books/university-physics-volume-3/pages/9-2-molecular-spectra)

含 N 个原子的分子有 3N 个位移自由度。扣除整体平移和转动，非线性分子有 3N−6 个振动自由度，线性分子有 3N−5 个。CO₂ 因而有 4 个振动自由度，其中两个弯曲方向简并，常说有三种基本振动频率。[CSU East Bay：振动模式与选择定则](https://chemistry.csueastbay.edu/~pfleming/chem/352/chap04/allowed-transitions.htm)

### 3. “红外活性”比能量匹配多了什么？

红外电场与电偶极矩耦合。常规电偶极基频条件写成：**(∂μ⃗/∂Q)₀ ≠ 0**，Q 是该振动的正常坐标。更严格的允许条件是上下态的跃迁偶极矩非零。永久偶极矩 μ⃗₀ 的大小，不能代替振动时的变化。

理想谐振近似、偶极矩对位移只保留线性项时，振动选择定则为 Δv = ±1；吸收对应 +1。非谐性和更高阶耦合可产生较弱的泛频与组合带。能量与选择定则都满足，只表示跃迁可以发生，不表示每个入射光子都必然被吸收。[CSU East Bay：红外跃迁](https://chemistry.csueastbay.edu/~pfleming/chem/352/chap04/IR-Spec.htm)

CO₂ 没有永久偶极矩，但反对称伸缩会改变瞬时偶极矩，气相强带约 2349 cm⁻¹；弯曲约 667 cm⁻¹ 也有红外活性。对称伸缩在理想对称分子的电偶极基频红外中不活跃，却可在 Raman 中出现。约 1333 cm⁻¹ 是未扰动对称伸缩的常用值；实际 Raman 中存在 Fermi 共振双峰，不能说“必定有一根 1333 的红外峰”。[NIST：CO₂ 振动频率表](https://webbook.nist.gov/cgi/cbook.cgi?ID=B4000020&Mask=800)

### 4. 干涉仪为什么能够编码？

两臂必须是同一输入分出的光，返回后空间重合且偏振条件允许。对单波数，理想输出功率可写成：

**P(δ) = Pmax[1 + cos(2πν̃δ)]/2。**

相位差 φ = 2πν̃δ；余弦走完一周期需要 δ 增加一个波长。1000 cm⁻¹ 的 OPD 周期为 10 μm，3000 cm⁻¹ 的 OPD 周期约 3.33 μm。因此扫描同样 10 μm，一个周期与三个周期可以直接比较。

一般光程是沿路径的折射率积分。空气、正入射、一个镜子沿轴移动时，Δδ ≈ 2Δx；若臂内有不同介质，不能只比较几何长度。教学模型选定 δ = 0 为两臂等光程原点。[JHU APL：傅里叶变换光谱原理](https://secwww.jhuapl.edu/techdigest/Content/techdigest/pdf/APL-V07-N02/APL-07-02-Hochheimer.pdf)

所谓“50/50 分束”通常指功率分配，场振幅系数的模为 1/√2，还含相位。两臂返回后再次经过分束器，不能把两束各“半功率”直接加成任意能量。理想无损两输出端口互补：一个增强，另一个减弱，总能量守恒。画面只观察其中一个端口。

普通热源的不同频率分量不要求彼此保持固定相位。**每个分量与自身经过两臂的副本产生干涉，再对探测器可响应的强度贡献求和。**宽带的相干长度有限，所以整体调制在等光程附近集中；不是不同颜色的电场被随意相加。[Thorlabs：Michelson 干涉与不同光源的相干性](https://www.thorlabs.de/newgrouppage9.cfm?objectgroup_id=10107&pn=EDU-MINT2%2FM)

探测器跟不上几十 THz 的红外电场。动镜以速度 vₘ 扫描时，δ(t) ≈ 2vₘt，强度调制频率为 **fₘ = 2vₘν̃**。用 cm/s 与 cm⁻¹ 得 Hz；如 vₘ = 0.1 cm/s、ν̃ = 1000 cm⁻¹，fₘ = 200 Hz。这个较慢的调制才被电学系统记录；不是分子的振动频率变慢了。

### 5. 交流信号、中心突峰与傅里叶关系

探测功率不为负。教学显示中去掉恒定基线后，交流信号 g(δ) 可正可负；负值表示低于基线。离散分量用非负强度权重 wⱼ：

**g(δ) = Σ wⱼ cos(2πν̃ⱼδ)。**

在理想零相位宽带模型中，可选如下配对约定：

**g(δ) = ∫₀∞ B(ν̃) cos(2πν̃δ) dν̃；**

**B(ν̃) = 2∫₋∞∞ g(δ) cos(2πν̃δ) dδ，ν̃ > 0。**

B 是包含系统响应的单光束谱密度；不是分子吸光度。教材可能把常数并入 B，或利用偶对称性改成单边积分，因此比较公式前要检查比例约定。网页离散恢复使用 2hΣ g(δᵢ)cos(2πν̃δᵢ)，对同一记录全体采样点求和。

δ = 0 时，各余弦项为 1，宽带贡献一起增强；离开零点后不同周期错开，很多正负贡献抵消，形成中心突峰与衰减。单一波数持续振荡；少量离散谱线可以反复增强，不能仅给它套一个包络就冒充宽带。ZPD 按等光程定义，真实相位误差、色散可改变峰形和位置，不应把任意最高点直接命名为 ZPD。[Shimadzu：Fourier Transform and Apodization](https://www.shimadzu.com/an/sites/shimadzu.com.an/files/pim/pim_document_file/journal/talk_letters/13258/jpa212011.pdf)

FFT 是快速计算 DFT 的算法。当前实现使用 2 的幂点数方便计算，不是物理定律；真实仪器还处理相位、加窗、采样非理想和噪声。

### 6. 为什么要背景参比？为什么取对数？

稳定条件下，设共同系统响应为 H(ν̃)：B背景 = H，B样品 = H·T。分别变换后，按同一波数取 B样品/B背景，得到 T。不能把两条干涉图逐点相除；不能把两条谱各自归一到最高峰后再取比。[Shimadzu：背景单光束谱与比值](https://www.shimadzu.eu/service-support/technical-support/ftir/tips_and_tricks/power.html)

A = −log₁₀T，%T = 100T。对数使连续吸收路径的乘法衰减变成可相加的吸光度；在满足 Beer–Lambert 条件时 **A = εcl**。浓度 c 用 mol/L、光程 l 用 cm，则 ε 用 L·mol⁻¹·cm⁻¹。均匀样品、适当谱带宽度、适当浓度范围与可忽略的额外散射等条件很重要；强吸收、反射、散射、化学平衡变化会使简单定量失效。[IUPAC：Beer–Lambert 定律](https://goldbook.iupac.org/terms/view/B00626)

背景不是“噪声清除器”。两次测量间水汽、CO₂、光源或位置改变，会留下残差；低背景处，分母过小会放大误差。网页把背景低于 0.035 相对单位的点留空，这是本模型阈值，不是行业统一阈值。[Shimadzu：环境水汽与 CO₂ 的影响](https://www.shimadzu.com/an/service-support/faq/ftir/4/index.html)

### 8. 分辨率、采样、补零、加窗：四件不同的事

设均匀 OPD 间距为 h、真实点数 N，DFT 格点间距是 **Δν̃格点 = 1/(Nh)**；补零到 zN 点后变成 1/(zNh)，原始记录没变。

若实际观察窗口是 −L 至 +L，矩形窗的线形含 sinc(2LΔν̃)，中心到第一零点间隔是 **1/(2L)**。标称分辨率还取决于单边/双边扫描约定、窗函数与分辨判据，不能脱离定义背一个“分辨率永远等于 1/L”。加 Hann 窗可降低旁瓣，但主瓣更宽、峰高也会改变。网页没有补偿 Hann 的幅度变化。

基带奈奎斯特上限为 **ν̃Nyquist = 1/(2h)**。h = 1 μm = 10⁻⁴ cm 时为 5000 cm⁻¹；若想保留至 4000 cm⁻¹，OPD 间距须小于 1.25 μm（实际应留余量），相应镜位移间距约为其一半。真实仪器还要控制能到达探测器的带外辐射，不能只把显示范围设为 4000 就避免混叠。

延长扫描增加对相近波数的区分能力；缩小采样间距提高可记录的基带上限；补零增加输出格点；加窗改变线形。真实仪器较高分辨率还可能需要更小光阑，牺牲通量，且样品本身宽带未必因此明显变窄。[Shimadzu：分辨率与光阑](https://www.ssi.shimadzu.com/service-support/technical-support/analysis-basics/tips-ftir/tech.html)

### 9. 真实参考谱的 k 到底是什么？

复折射率采用 n̂ = n + ik 的约定。n 描述传播相位，k 与吸收衰减有关；这里 k 无量纲。对理想均匀介质内部、不含界面反射的单程传播：

**α = 4πν̃k；I(l) = I(0)e^(−αl)；A = αl/ln10。**

ν̃ 用 cm⁻¹、l 用 cm，则 α 用 cm⁻¹。由此可见 k ≠ A；比较两者需波数和光程，实际窗口/界面还需反射处理。[PNNL 官方样品说明：k 与吸收系数关系](https://webbook.nist.gov/chemistry/silmarils-liquids-n-k/docs/META.MIR.PUR.Polystyrene.LIQ.SIGMA-ALDRICH.PNNL513043.pdf)

丙酮、乙醇来自 2025 年 PNNL n/k 数据集。该库含 111 种液体，覆盖约 10000–400 cm⁻¹；网页只展示 4000–400 的范围。官方要求结合每个样品的元数据使用。[PNNL：2025 数据集](https://data.pnnl.gov/group/nodes/dataset/34312)

| 当前参考 | 课堂可用线索 | 必须保留的限定 |
|---|---|---|
| 丙酮，液体 | 本冻结数据约 1715 cm⁻¹ 的强 C=O 相关带 | 峰位随环境与相态变化；NIST 的液态频率表给出约 1710.5 cm⁻¹，不能把 1715 当万能身份证 |
| 乙醇，液体 | 3200–3600 cm⁻¹ 的 O–H 宽带、约 1050 cm⁻¹ 的 C–O 主贡献 | 氢键和耦合影响带形；1050 不宜说成完全孤立的一根键在振动 |
| 苯乙烯低聚物，液体 | 芳香 C–H、环骨架以及低波数指纹组合 | 文件名为 polystyrene；实际来源记录为 Styrene, oligomers，不是普通固体 PS 薄膜 |

丙酮依据：[NIST：丙酮振动表](https://webbook.nist.gov/cgi/cbook.cgi?ID=C67641&Mask=800)。乙醇与芳香结构标注依据：本项目 `reference-data/annotations.json`；[AIST SDBS：乙醇液膜参考](https://sdbs.db.aist.go.jp/CompoundLanding.aspx?sdbsno=1300)、[聚苯乙烯振动归属研究](https://pubs.rsc.org/en/content/getauthorversionpdf/C4CP03516J)。后两者用于核对归属，不是网页当前曲线的采集来源。

苯乙烯低聚物是 2017 年 PNNL/NIST 参考记录；官方元数据明示样品 26±1 °C、Bruker Tensor 27、2.0 cm⁻¹ 分辨率、128 次干涉图平均、Norton–Beer Medium 加窗与 Mertz 相位校正。这些是**来源数据的真实采集条件**，不是网页模拟条件。[NIST：原始记录](https://webbook.nist.gov/cgi/cbook.cgi?Contrib=IARPA-IR-L&ID=C9003536&Index=0&Type=IR-SPEC)

NIST SRM 1921b 是约 38 μm 的聚苯乙烯薄膜波数标准，认证峰位用于检查标尺。它与网页低聚物曲线是两个对象，认证峰位表不等于一张完整实测谱。当前查阅证书签发于 2026-09-15。[NIST：SRM 1921b 证书](https://tsapps.nist.gov/srmext/certificates/1921b.pdf)

### 10. 老师问到 ATR 或 FTIR 优势时

ATR 通过高折射率晶体界面处的倏逝场与紧密接触的样品相互作用。弱吸收近似下，常用特征穿透深度：

**dₚ = λ₀/[2πn₁√(sin²θ − (n₂/n₁)²)]。**

n₁ 为晶体、n₂ 为样品折射率，θ 从界面法线计，须满足全反射条件。这里按**场振幅衰减到 1/e**定义 dₚ，强度衰减到 1/e 的长度为 dₚ/2；不要混用两种约定。[NIST 研究论文：倏逝场振幅与穿透深度，第 8–9 页](https://tsapps.nist.gov/publication/get_pdf.cfm?pub_id=913386)

波长更长时深度通常更大，深度还依赖角度和折射率。dₚ 不是一层硬边界，也不直接等于透射有效光程；偏振、反射次数和接触会影响吸收。[Specac：ATR 深度与有效光程](https://specac.com/wp-content/uploads/2022/03/TN21-02-ATR-Penetration-Depth.pdf)

透射可用薄膜、液体池、气体池、KBr 压片；ATR 常适合厚样品、粉末、黏稠液体等。ATR 与透射的相对峰强可能不同，检索和比较须注意采样方式。网页当前没有模拟 ATR 深度或接触压力。[Thermo Fisher：ATR 原理](https://knowledge1.thermofisher.com/@api/deki/files/29384/FT-IR_-_Introduction_to_Attenuated_Total_Reflection_(ATR)_Spectroscopy.pdf?revision=1)

FTIR 常说的优势：同时编码多波数的 Fellgett 优势、较高通量的 Jacquinot 优势、光学标尺帮助稳定波数轴的 Connes 优势。多路复用的信噪改善有条件，典型条件是信号无关的探测器噪声占主导；光子噪声可能把强分量噪声分布到其他谱区，不能承诺任何样品都更灵敏。[JHU APL：多路复用与通量](https://secwww.jhuapl.edu/techdigest/Content/techdigest/pdf/APL-V07-N02/APL-07-02-Hochheimer.pdf)、[Voigtman 与 Winefordner：多路复用的噪声限制](https://opg.optica.org/as/abstract.cfm?uri=as-41-7-1182)。波数轴仍须验证与校准；有参考激光不等于全部测量误差消失。

## 四、老师提问：先给 20 秒短答，再按需展开

### 必答：建立主链路

**1. FTIR 到底测什么？**

短答：测样品与红外辐射相互作用后，各波数的透射或吸收信息。探测器先记录干涉图，计算并参比后才得到吸收相关结果。

**2. 为什么选红外，不用可见光？**

短答：很多分子振动跃迁的能量与红外光子匹配，所以红外能提供振动和结构线索。可见光常涉及不同类型的跃迁；不是同一种信息换个颜色看。

**3. 是不是所有分子、所有振动都吸收红外？**

短答：不是。要看振动能否改变偶极矩，以及光子能量是否匹配允许跃迁。不同振动的强度也不同。

**4. CO₂ 没有永久偶极矩，为什么仍吸收？**

短答：永久偶极为零，不代表振动过程偶极不变。反对称伸缩和弯曲会产生变化，所以它们可有红外活性。

**5. 对称伸缩不活跃，是不是它根本不振动？**

短答：振动存在，只是该理想对称模式的电偶极基频红外跃迁不活跃。它还可能通过 Raman 等方式研究。

**6. 红外能量更高，是不是吸收就更强？**

短答：更高只意味着光子能量更大；吸收还取决于能级间隔、选择定则和跃迁强度。不能把多出来的能量随意塞进一个跃迁。

**7. 波数是不是频率？**

短答：它们成正比但单位不同。波数用 cm⁻¹，频率用 Hz；乘以对应单位的光速即可换算。

**8. 一个总读数为什么不够？**

短答：不同波数组成能给出相同总读数。网页两组贡献都加到 2，所以需要更多测量变化来恢复组成。这不表示所有探测系统都只能测一个数。

**9. 分束器是不是把不同波长分到两边？**

短答：这里它把同一输入分成两条光臂，每条臂都可含多种波数。它不是按波数分类的滤色器。

**10. 动镜是不是正在扫描波长？**

短答：它扫描光程差，让各波数同时留下不同的起伏周期；不是依次只放行某一种波长。

**11. 为什么 OPD 是镜位移的两倍？**

短答：动镜远离时去程多走一次 Δx，回程也多走一次 Δx，所以多 2Δx。这个关系采用空气、正入射近似。

**12. 为什么高波数起伏更快？**

短答：高波数意味着波长更短。同样增加一段 OPD，会跨过更多波长，所以经历更多明暗周期。

**13. 干涉图的横轴是不是时间？**

短答：网页按 OPD 排列。真实连续扫描随时间采集，再借标尺对应到 OPD；只有扫描条件确定后两者才能换算。

**14. 为什么图中出现负值？**

短答：这里已经减去恒定基线。负值表示低于基线，不是负光功率，也不是样品发出了“负的光”。

**15. 中心突峰是什么意思？**

短答：理想零相位宽带光在等光程位置，各分量的正贡献共同增强。离开后不同周期错开，很多贡献抵消。

**16. 单一波数也有同样的孤立中心突峰吗？**

短答：没有。理想单一波数持续周期起伏；明显集中的宽带中心突峰需要多波数分布。少量离散线还会重复增强。

**17. 不懂傅里叶公式，怎么解释它？**

短答：一条复杂起伏含有多种快慢不同的节奏。傅里叶变换用整条记录计算每种节奏的贡献，再按波数排列。

追问：它利用线性分解，不是靠看曲线形状猜几个峰；记录有限和有噪声时，恢复也有限制。

**18. 变换之后是不是已经得到吸收谱？**

短答：先得到单光束谱，其中还有光源、光学和探测器响应。与背景比较后才能得到透射率，再转换成吸光度。

**19. 为什么样品除以背景，而不是相减？**

短答：共同响应与透射率在模型中是乘法关系。相除才能去掉共同因子。相减表示绝对损失，仍受光源强弱影响。

**20. 能不能直接把两个干涉图相除？**

短答：不能把这个比值当透射率。应先分别变换，得到相同波数上的两个谱响应，再作比值。

**21. T、%T、A 怎样区别？**

短答：T 是透射比例，%T = 100T，A = −log₁₀T。10% 透射应先用 T = 0.1，再算得 A = 1。

**22. 吸光度就是“吸走百分之多少”吗？**

短答：不是。吸光度是对透射比例取负对数。忽略反射、散射时，吸收比例才近似 1−T；它与 A 是不同的量。

**23. 一个 1715 的峰就证明是丙酮吗？**

短答：不能。它支持羰基相关线索，很多物质都可能有类似带。还要看其他峰、指纹区和相态等条件。

**24. 这套网页演示是真实实验吗？**

短答：光路和数字测量是教学模型；真实参考谱另有 PNNL 来源。模拟验证原理，不能宣称完成了实物仪器采集。

### 进阶：被追问时再讲

**25. 红外与 Raman 有什么区别？**

短答：红外活性关联振动引起的偶极矩变化，Raman 活性关联极化率变化。两者可以互补，不能说一切分子都严格互斥。

追问：理想具有反演中心的分子有互斥规则；没有反演中心时同一模式可能两者均活跃。见上文 CSU 模式资料。

**26. 分子已经在振动，吸收后发生什么？**

短答：分子由较低振动量子态跃迁到较高态。随后可通过碰撞和其他弛豫途径重新分配能量；动画不是单个光子必定被吸收的录像。

**27. 为什么真实谱是宽带，不是一根无限细线？**

短答：分子环境、碰撞、寿命、振转结构等可影响线宽和谱带；仪器有限分辨率又会展宽观测结果。液态氢键也可使 O–H 带变宽。

**28. 热源不相干，为什么还能干涉？**

短答：同一输入分成的两份仍具有可比较的关联；各频率与自身副本干涉。宽带整体的调制集中在有限的相干长度附近。

**29. 相消时能量去哪里？**

短答：理想无损干涉仪的另一个输出端口相应增强。能量在端口间重新分配；它不会因某一端口变暗就凭空消失。

**30. 参考激光是否用来测样品吸收？**

短答：这里它提供长度与波数标尺，宽带红外才承担样品测量。网页没有给出某型号的具体共路激光方案。

**31. 怎样提高分辨率？多画一些点就行吗？**

短答：要增加有效扫描信息并考虑窗函数、光阑与判据。补零只细化谱格点，不能让原本分不开的两个峰自动变得可分辨。

**32. 加窗是不是单纯把曲线弄漂亮？**

短答：加窗是对干涉记录加权，降低截断旁瓣；代价是主瓣展宽和幅度变化。应按分析目的选择，并报告处理条件。

**33. 更高分辨率是不是永远更好？**

短答：未必。扫描时间和通量有代价，样品本身若是宽谱带，继续提高仪器分辨率也不一定增加有用信息。

**34. 增加扫描次数能提高什么？**

短答：稳定、独立随机噪声近似下，平均 M 次常使信噪比按 √M 改善；要翻倍大约需四倍次数。它不会自动提高分辨率或消除漂移。

**35. 测到很多水汽或 CO₂ 残峰怎么办？**

短答：先核对背景与样品的时间、环境和附件条件，尽量稳定光路、及时参比，必要时用干燥空气或氮气吹扫。软件校正不能取代判断真实来源。

**36. 样品太厚、峰顶饱和或基线乱怎么办？**

短答：先检查单光束能量、样品光程/浓度、窗口和散射；透射可考虑适当减薄或缩短光程，ATR 则检查接触和适配附件。按实验室方法调整，不能只平滑掉问题。

**37. ATR 光谱能直接与透射光谱比峰高吗？**

短答：不宜直接定量比较。ATR 的有效相互作用深度随波数、材料、角度和接触变化，必要时用适当校正和同方式参考谱。

**38. FTIR 能不能测混合物、定量或证明全部结构？**

短答：可以为混合物与定量提供数据，但重叠峰、未知组分和测量误差会限制分析。定量需校准和适用条件；完整结构通常还需 NMR、质谱等其他证据。

## 五、网页自由实验：每次只验证一个问题

以下控件名称按当前实现核对。主课堂结束后再选 1–2 项，避免把所有高级实验压进首次讲解。

| 入口与约需时间 | 建议操作 | 希望学生看到的关系 |
|---|---|---|
| 能级与吸收，1 分钟 | 点“匹配能级差”，再点“换成更高能量”；切换“振动使偶极矩改变” | 能量匹配与活性是两道条件；1700 cm⁻¹ 为假想零线宽模式 |
| 仪器全景，2 分钟 | 切“光学核心”和“俯视”；用“追踪光路”；在“部件”选动镜或分束器 | 路径先分开、返回，再汇合；部件展开是功能示意，不是拆装规程 |
| 镜位移实验，1 分钟 | 展开“查看镜位移怎样改变探测信号”；选虚拟 1000/3000；使用“+0.25 μm” | 镜位与 OPD 的二倍关系；高波数在同样 OPD 区间中更多起伏 |
| 信号怎样叠加，1 分钟 | 依次“单分量”“两个分量”“三个分量”“连续宽带近似” | 多个贡献逐点相加；连续宽带是另一个模型，不能直接比较其幅度单位 |

| 判断测量质量，2 分钟 | 先改变“有效扫描”，再单独换“补零”，最后换“窗函数” | 真实信息、显示格点和线形之间的区别；不要同时改多个变量 |
| 模拟实验室弹窗，1 分钟 | 切“3D 仪器结构”与“真实参考谱”；更换样品 | 四大模块与参考谱身份；弹窗只有结构和真实谱，不是上述完整测量工作台 |

## 六、最容易说错的句子

| 容易误说 | 建议说法 |
|---|---|
| 分子有偶极矩才能吸收红外 | 相应振动引起偶极矩变化，才满足常规电偶极基频活性条件 |
| CO₂ 的两个分子，一个吸收一个不吸收 | 同一个 CO₂ 分子的两种振动模式，红外活性不同 |
| 镜子把每个波长逐个选出来 | 镜子改变 OPD，各波数同时编码为不同周期 |
| 探测器跟着光的电场振动 | 探测器记录动镜造成的较慢强度调制 |
| 相消就是光能消失 | 单端口响应减弱；理想情况下另一端口增强 |
| 中心突峰就是任何曲线的最高点 | ZPD 是等光程位置；理想零相位宽带在那里形成中心突峰 |
| 变换后就是吸收谱 | 先得到单光束谱，再背景参比得到 T 与 A |
| 背景消除了全部误差 | 稳定的共同系统响应可被参比抵消；变化、噪声和样品效应仍需处理 |
| 补零提高真实分辨率 | 补零细化输出格点；有效扫描与窗函数决定线形等分辨能力 |
| k 谱就是吸光度谱 | k 是无量纲虚部折射率，与吸收相关但不等于 A |
| 网页聚苯乙烯就是认证标准片 | 网页是液态苯乙烯低聚物参考；SRM 薄膜标准是另一对象 |

遇到超出自己准备的问题，可先准确回答范围：“这里演示的是理想透射模型；实际仪器的这个数值还要看型号、附件和采集条件。”随后指向对应的采集元数据或方法定义，保持已经讲清的因果链。

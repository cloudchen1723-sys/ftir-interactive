# 五分钟课堂讲稿｜从分子振动到红外光谱

适合完全没有接触过红外光谱的大学生。对应当前离线 HTML 的首页及 01–09 主线，**目标用时 4 分 40 秒，预算包括展示和操作**。这次只讲清一条因果链，不要求听众掌握每个停点的细节。

课前打开网页，回到首页，确认画面和参考谱正常显示；正式计时从开场第一句话开始。预加载不占用课堂时间，进入课堂的点击和全部主线展示占用课堂时间。按手动模式演示，不开启额外实验或问答。

## 讲者操作约定

- 点击首页“开始探索”，即进入 01/b0。之后只用空格或舞台空白处推进，等待动画结束再按下一次；不要连续按空格。
- b0 是每页入场状态。下一页 b0 也由一次正常推进进入。01–09 共 39 个稳定停点，从 01/b0 到 09/b2 共需 38 次推进。
- 03/b1、03/b4 的光路各自动播放一次完整的①–④，不需要逐段点击。其他时间可以边讲边看；讲到对应的句子再推进，不把动画全部挤到讲完以后。
- 方括号内的操作提示和时间不朗读。下面每段正文都可以直接照讲。不会要求听众回答问题或额外等候。

## 可直接照讲的正文

### 首页｜0:00–0:10

[开始计时。说完后点击“开始探索”。]

<!-- SPOKEN START -->
一瓶无色液体是什么？我们可以用红外光，寻找分子结构的线索。
<!-- SPOKEN END -->

### 01｜0:10–0:43

[b0 说第一句；b1 看对称伸缩；b2 讲“另一种伸缩”；b3 讲能量条件。最后推进到 02/b0。]

<!-- SPOKEN START -->
分子里的原子会振动。看二氧化碳：这种对称伸缩，两边电荷分布的变化互相抵消；另一种伸缩，让正负电荷的偏向不断改变。这个偏向叫偶极矩。振动引起偶极变化，且光的能量匹配，才会发生相应的红外吸收。
<!-- SPOKEN END -->

### 02｜0:43–1:05

[b0 讲前两句；b1 改变组成；b2 出现起伏记录的思路，再推进。]

<!-- SPOKEN START -->
不同波长的光，用波数来区分。波数越大，波长越短。宽带探测器一次只报总量。看，组成变了，总量却相同！要分清各有多少，我们得让不同波数留下不同的变化节奏。
<!-- SPOKEN END -->

### 03｜1:05–1:44

[b0 指光源、样品、探测器；b1 按一次空格，完整看 4.25 秒光路，讲第二句；b2 讲三个部件的作用；b3 转俯视；b4 再按一次，完整看光路，讲最后一句。结束后推进。]

<!-- SPOKEN START -->
跟着三维光路看：光源提供光，样品吸收一部分，探测器记录剩下的光。光先在分束器分成两路，分别碰到镜子，再反射回来汇合。分束器负责分开和重合，固定镜保持一路长度，动镜改变另一路。再看一遍：分开、返回、汇合，再经过样品和探测器。
<!-- SPOKEN END -->

### 04｜1:44–2:19

[b0 定义光程差；b1 移镜；b2 讲去程；b3 讲回程；b4 讲两倍；b5 看起伏对比，再推进。每次等对应动画结束。]

<!-- SPOKEN START -->
两路光走过的光学路程之差，叫光程差。动镜移一段，光去时多走一段，回来又多走一段，所以光程差改变两倍。两路光汇合时有时增强、有时减弱。看同一段光程差：波数越大，探测读数的起伏越密。
<!-- SPOKEN END -->

### 05｜2:19–3:03

[b0 看逐点记录；b1 去掉基线；b2 单分量；b3 加第二种；b4 加第三种；b5 换宽带；b6 看中央；b7 看两翼，再推进。让曲线画完再按下一次。]

<!-- SPOKEN START -->
每到一个光程差位置，记一个功率读数。减去恒定基线后，曲线会有负值，只是低于基线，并非负的光功率。一种光留下一个节奏；各个贡献在同一位置相加。现在换成连续宽带光，得到复杂的干涉图。中央两路等光程，各贡献同向叠加；两边逐渐错开，大多抵消。
<!-- SPOKEN END -->

### 06｜3:03–3:31

[b0 保留同一记录；b1 回顾快慢；b2 边看波数谱展开，边讲转换结果；b3 说名称；b4 讲最后一句，并在这句后半段推进到背景展示。]

<!-- SPOKEN START -->
不同波数留下不同节奏，就能从这同一条完整记录里，找回它们各自的强弱。这种计算叫傅里叶变换。横轴从光程差变成波数，混在一起的贡献被展开了。不过，结果仍受到光源和仪器响应的影响。
<!-- SPOKEN END -->

### 07｜3:31–3:59

[b0 看背景；b1 加样品；b2 在同一波数取比；b3 转吸光度，再推进。]

<!-- SPOKEN START -->
所以先测背景，再测样品。把两次得到的谱，在相同波数处用样品除以背景，得到透射率。再换成吸光度：透过越少，吸光度越大，吸收就显示为向上的峰。
<!-- SPOKEN END -->

### 08｜3:59–4:17

[只停 b0，让丙酮参考谱显示；不用“探索主要吸收带”，不换样品。说完推进到 09/b0。]

<!-- SPOKEN START -->
这里换成真实的丙酮参考数据，来自 PNNL 数据库，并非网页实测。纵轴是描述吸收性质的虚部折射率，和刚才的吸光度不同。
<!-- SPOKEN END -->

### 09｜4:17–4:40

[b0 指吸收带；b1 看碳氧双键伸缩；b2 等整条流程完整显示，讲最后两句；结束计时。]

<!-- SPOKEN START -->
约一千七百一十五波数附近这条带，主要来自碳氧双键伸缩。它是结构线索，鉴定还要看完整光谱。从振动、吸收，到干涉记录、计算和背景比较，我们就能读懂这些线索。
<!-- SPOKEN END -->

## 计时与赶进度｜仅供讲者

目标 4:40，剩余 20 秒用于现场操作迟疑或加载波动。不要把 5:00 当成正常结束点。上台前按相同页面和操作完整排练一次；如果不能在 4:40 左右结束，先缩短口述，保留正常操作。
